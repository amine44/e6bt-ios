File format, calculations & planning notes

Save plan downloads an editable JSON file. Load file restores this planner’s JSON format; it does not read proprietary files from other planners. Imports are checked before replacing your plan, and the previous plan remains available with Undo. Files are processed locally and are not uploaded. CSV is a calculated report for spreadsheets; JSON is the reloadable format.

True heading = true course + wind correction. Magnetic heading = true heading − east variation. Compass heading = magnetic heading − east deviation. Leg time = distance ÷ ground speed. Fuel used = time × fuel flow. Arrival fuel subtracts taxi/start and all leg fuel. Reserve fuel uses the final leg’s fuel flow and your entered reserve duration; this is a planning target, not a regulatory determination.

An incomplete or impossible leg stops cumulative time/fuel calculations for following legs. Individual valid later legs can still calculate. No route, terrain, weather, airspace, alternates, climb/descent performance, or legal VFR/IFR requirements are checked. Altitude in direct-TAS mode is a planning note; IAS mode requires pressure altitude. Fuel units label your inputs and do not convert existing numbers.
